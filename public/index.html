Step 1: Telegram API Credentials

Get these for free from my.telegram.org (Log in → API development tools).

Step 2: Telegram Bot Token

Open Telegram and chat with @BotFather. Send /newbot, give it a name, and copy the HTTP API token.

Step 3: Private Storage Channel

1. Create a Private Channel in Telegram (e.g. My TeleDrive Vault).
2. Add your Bot as an Administrator with post permissions.
3. Paste the Channel ID below (usually starts with -100).

Tip: Forward any message from the channel to @userinfobot or @JsonDumpBot to see the channel ID.
Step 4: Master Security Passwords

Your files will be encrypted using AES-256-GCM. Please choose a strong password. If you lose this password, encrypted files cannot be decrypted.

You can use the same as your master password or a separate phrase.
Step 5: Verify Connection

Click "Test Connection" to check if the Bot can connect to Telegram MTProto and write to your channel.
